Android 17 QPR2 정식 릴리스 살펴보기

2026년 11월 14일 · 약 4분
Way
Android Developer

안녕하세요, 한국투자증권에서 한투-한국투자증권 개발을 담당하고 있는 way입니다.

2026년 11월 10일에 정식 릴리스된 Android 17 QPR2에 대해 설명해드리겠습니다.

배경​

QPR은 분기마다 배포되는 플랫폼 릴리스입니다.
메이저 버전 사이의 공백을 메우며 기능 개선과 보안 패치를 함께 전달합니다.

이번 QPR2는 일정보다 한 달 앞당겨 배포되었습니다.
작년 Android 16 QPR2가 12월에 배포된 것과 비교하면 이례적인 일정입니다.
11월 Pixel Drop과 2026년 11월 5일 보안 패치 수준이 함께 적용되었습니다.

대상 기기는 Pixel 6a부터 Pixel 11 시리즈까지 23종입니다.
Pixel Fold와 Pixel Tablet도 포함됩니다.
Pixel 6과 Pixel 6 Pro는 이번 릴리스 대상에서 제외되었습니다.
두 기기의 5년 업데이트 지원 기간이 2026년 10월에 종료되었기 때문입니다.

Android 17 QPR2 살펴보기​

지원 기기와 빌드 번호​

대부분의 기기에는 CP4A.261105.040.A1 빌드가 배포됩니다.
Pixel 11 시리즈는 지역에 따라 빌드 번호가 나뉩니다.
미국 모델은 CP4A.261105.040.D1, 캐나다 모델은 CP4A.261105.040.B2입니다.
배포는 단계적으로 진행되며 일주일 정도에 걸쳐 전 기기에 도달합니다.

단말에 적용된 보안 패치 수준은 코드에서도 확인할 수 있습니다.

val securityPatch = Build.VERSION.SECURITY_PATCH
// 기대값: 2026-11-05

또는 adb 명령으로 확인할 수 있습니다.

adb shell getprop ro.build.version.security_patch

맞춤 설정과 블러 효과​

시스템 색상을 직접 조절하는 슬라이더가 추가되었습니다.
강도는 Neutral, Soft, Bright, Bold 네 단계로 나뉩니다.
라이트 모드와 다크 모드에 각각 대응하는 적응형 배경화면도 지원됩니다.

개발자는 앱 안에서 새로운 블러 효과를 사용할 수 있습니다.
미디어 위에서 동작하는 오버레이에 적합한 형태로 개선되었습니다.
잠금 화면 위젯 편집 화면과 전원 메뉴의 블러 표현도 함께 다듬어졌습니다.

상태 표시줄과 빠른 설정​

상태 표시줄 옵션이 새로 추가되었습니다.
표시할 알림 종류와 시스템 모드 표시 여부를 선택할 수 있습니다.
빠른 설정에서는 앱이 실행 중일 때도 화면 밝기를 조절할 수 있습니다.
키보드 전환 버튼과 프린터 전송 시의 Live Updates 표시도 추가되었습니다.

음성 브로드캐스트와 블루투스​

Voice broadcast 기능이 추가되었습니다.
음성을 Auracast 수신 기기로 직접 스트리밍할 수 있습니다.
빠른 설정에 오디오 스트림 항목이 생겼고 Live Caption과 번역을 함께 사용할 수 있습니다.
블루투스 오디오에서 Gemini 음성과 미디어 음량 차이도 완화되었습니다.
암호화 DNS 서버 지원과 공유 시트 개선도 포함되었습니다.

보안과 개인정보 보호​

Private Compute Core logging 기능이 추가되었습니다.
AI 앱이 단말 데이터에 접근한 내역을 사용자가 직접 확인할 수 있습니다.
연락처 편집 권한 체계도 변경되었습니다.
기존처럼 권한만으로 연락처를 직접 수정하는 방식에서 벗어납니다.
통화 착신 전환을 이용한 사기 시도를 막는 보호 기능이 추가되었습니다.
멀티 SIM을 지원하는 SIM 보안 타임라인 뷰어도 제공됩니다.
사이드로딩 시 권한을 부여하는 절차도 간소화되었습니다.

멀티태스킹과 접근성​

폴더블 기기의 멀티태스킹이 개선되었습니다.
앱 핸들이 상단에 배치되고 분할 화면 전환이 부드러워졌습니다.
Bubbles의 위치 조정과 전체 화면 전환, 실행 동작도 개선되었습니다.
Linux Terminal에서는 실행 중인 리눅스 세션의 파일을 앱에서 탐색할 수 있습니다.
USB 웹캠으로 사용할 때의 화면과 화면 녹화 기본 동작도 변경되었습니다.
색상 인식 관련 조정과 블루투스 보청기 잠금 화면 제어 기능이 추가되었습니다.
선호하는 홈 시간대 설정과 키보드 진동 강도 조절 슬라이더도 제공됩니다.

실무 관점​

QPR 릴리스는 OS 동작이 바뀌는 지점이라 실무 앱에 미치는 영향을 먼저 확인해야 합니다.
연락처 편집 권한 변경처럼 타깃 SDK와 무관하게 적용되는 변경이 포함될 수 있습니다.
Pixel 실기기가 있다면 보안 패치 수준부터 확인하고 주요 플로우를 회귀 테스트하는 것이 좋습니다.
베타 기간에 테스트했던 Quick Settings 레이아웃 편집 기능은 정식 릴리스에서 빠졌습니다.
베타에서 확인한 기능이 정식에 그대로 포함된다고 단정하지 않는 것이 좋습니다.
다음 분기 릴리스인 QPR3는 이미 베타가 진행 중이며 내년 봄 배포가 예상됩니다.

마치며​

Android 17 QPR2는 맞춤 설정과 보안, 멀티태스킹을 함께 개선한 분기 릴리스입니다.
Pixel 6a 이후 기기를 사용 중이라면 단계적 배포 일정에 따라 순차적으로 받아볼 수 있습니다.

Android Canary 2611 살펴보기 — App Lock 복귀와 버블·카메라 단축키

2026년 11월 10일 · 약 4분
Way
Android Developer

안녕하세요, 한국투자증권에서 한투-한국투자증권 개발을 담당하고 있는 way입니다.
2026년 11월 4일에 공개된 Android Canary 2611에 대해 설명해드리겠습니다.
이번 빌드는 App Lock 복귀와 작은 단축키 추가가 중심입니다.

배경​

Android Canary는 Google이 매달 내놓는 가장 실험적인 테스트 트랙입니다.
정식 베타보다 한 단계 앞에 있고, 새로운 작업이 가장 먼저 도착합니다.
지난달 Canary 2610은 10월 중순을 넘겨서 나왔고, 2611은 11월 초에 나왔습니다.
월간 리듬이 다시 빨라진 셈입니다.
이번 변경점 가운데 일부는 10월 29일에 나온 Android 17 QPR3 Beta 3에도 들어 있습니다.
Canary와 베타 트랙이 같은 작업을 서로 다른 단계에서 나르는 경우입니다.
QPR3 Beta 3은 11월 1일 글에서 이미 다뤘으니, 이번 글은 Canary 트랙 자체에 초점을 맞춥니다.

Android Canary 2611 살펴보기​

Canary 트랙의 위치 이해하기​

Canary는 베타보다 앞서 가는 월간 트랙입니다.
베타에 오르기 전의 작업이 먼저 들어오고, 거친 부분이 남아 있을 수 있습니다.
Canary에서 본 기능이 그대로 정식 릴리스에 이른다는 보장은 없습니다.
기능이 바뀌거나 미뤄지거나 아예 나오지 않을 수도 있습니다.
그래서 Canary는 일상 기기가 아니라 테스트 기기에서 쓰는 트랙입니다.
설치는 Android Flash Tool에서 할 수 있습니다.

App Lock 다시 살펴보기​

App Lock이 Canary 2611에 돌아왔습니다.
앱마다 잠금을 걸어 기기 인증 뒤에만 열리게 하는 기능입니다.
빌린 기기나 잠금 해제된 기기에서 민감한 앱이 그대로 열리는 일을 막습니다.
App Lock은 QPR2 베타에서 잠시 빠졌다가 다듬는 과정을 거쳤습니다.
10월 29일 QPR3 Beta 3에서 복귀했고, Canary 트랙에서도 같은 작업이 이어지고 있습니다.
12월 Pixel Feature Drop은 QPR2 기반이라, App Lock이 정식에 이를지는 그때 확인할 수 있습니다.

Recents 화면에서 버블로 실행하기​

Recents 화면에 앱을 버블로 여는 단축키가 새로 생겼습니다.
버블은 대화를 작은 떠 있는 창으로 유지하는 Android의 멀티태스킹 방식입니다.
Recents 드롭다운 메뉴에서 Bubble을 고르면 앱이 바로 버블에 들어갑니다.
설정을 뒤지거나 전체 앱 목록을 거치지 않아도 됩니다.
다른 앱을 쓰면서 대화를 곁에 두는 흐름이 짧아집니다.

Quick Settings 카메라 타일과 At a Glance 알람 표기​

Quick Settings에 카메라를 여는 전용 타일이 추가되었습니다.
화면을 쓸어내리고 타일 하나만 누르면 카메라가 열립니다.
앱 아이콘을 찾거나 잠금 화면 단축키를 거치는 일을 줄입니다.
잠금 화면의 At a Glance 위젯도 바뀌었습니다.
다가오는 알람 시간에 오전과 오후를 구분하는 접미사가 표시됩니다.
작은 표기지만, 알람 시간을 잘못 읽는 실수를 줄이는 변경입니다.

빌드 정보와 설치 방법 확인하기​

Canary 2611의 빌드 번호는 ZP11.261016.008입니다.
업데이트 크기는 약 1GB로 안내되었습니다.
설치 이미지는 Pixel 6a 이상 기기에 제공됩니다.
Pixel 11 시리즈까지 포함하고, Pixel Fold와 Pixel Tablet도 대상입니다.
업데이트 전에는 배터리를 50% 이상 충전하는 것이 좋습니다.
Canary에 올린 Pixel은 이후 매달 새 Canary 빌드로 자동 업데이트됩니다.

# Android Flash Tool에서 Canary 이미지를 설치합니다
# https://flash.android.com/ 에서 기기를 연결하고 안내를 따릅니다

실무 관점​

Canary는 정식 릴리스가 아니니 실무 기기에 바로 올리지 않는 것이 좋습니다.
테스트용 Pixel이 있다면 그 기기에서 먼저 확인하는 흐름이 맞습니다.
App Lock처럼 사용자에게 보이는 기능은 정식 일정이 정해지기 전까지 기획에 반영하지 않는 것이 좋습니다.
QPR3 Beta 3과 겹치는 변경은 베타 트랙의 동작을 Canary에서 미리 보는 용도로 이해하면 됩니다.
다음 안정적인 이정표는 12월 Pixel Feature Drop이며, QPR2 기반입니다.

마치며​

Canary 2611은 App Lock 복귀와 작은 단축키 추가로 월간 트랙의 리듬을 이어갑니다.
테스트 기기에서 먼저 확인하고, 정식 릴리스에 맞춰 대응을 정리해 두는 것이 좋습니다.

Android 17 QPR3 Beta 3 살펴보기, API 변경 없는 분기 업데이트의 테스트 포인트

2026년 11월 1일 · 약 3분
Way
Android Developer

안녕하세요, 한국투자증권에서 한투-한국투자증권 개발을 담당하고 있는 way입니다.
2026년 10월 29일에 공개된 Android 17 QPR3 Beta 3에 대해 설명해드리겠습니다.

배경​

Android 17 정식 버전이 공개된 이후에도 플랫폼 업데이트는 분기 단위로 계속 이어집니다.
이 분기 업데이트를 Quarterly Platform Release라고 부릅니다.
QPR은 AOSP와 Pixel 기기에 Feature Drop 형태로 전달됩니다.
QPR3는 10월 초 Beta 1, 10월 중순 Beta 2에 이어 세 번째 베타 빌드입니다.
이번 베타는 새로운 API를 추가하지 않고, 보고된 문제를 수정하는 데 초점을 맞추고 있습니다.

Android 17 QPR3 Beta 3 살펴보기​

QPR의 성격​

QPR은 메이저 버전 업그레이드와 성격이 다릅니다.
앱에 영향을 주는 API 변경을 포함하지 않습니다.
따라서 기존 앱의 동작이 API 변경으로 깨질 가능성은 낮습니다.
대신 시스템 동작과 기기별 문제가 수정되며, 앱 호환성 테스트의 의미가 큽니다.

빌드 정보​

이번 베타의 빌드 번호는 기기별로 두 가지로 나뉩니다.
Pixel 11 시리즈는 DP11.261016.004 빌드를 사용합니다.
그 외 지원 기기는 DP11.261016.003 빌드를 사용합니다.
보안 패치 수준은 2026년 10월 5일 기준입니다.
Google Play 서비스는 26.36.33 버전이 함께 제공됩니다.
지원 대상은 Pixel 6a 이후 모델과 Android Emulator입니다.

Beta 3에서 수정된 내용​

공식 릴리스 노트에 따르면 이번 베타에서는 26건의 문제가 수정되었습니다.
대표적인 수정 항목은 다음과 같습니다.
Multiply 블렌드 모드 사용 시 이미지가 잘못된 투명도로 렌더링되던 문제입니다.
빠른 앱 전환 직후 홈 제스처를 수행할 때 Recents 화면이 깜빡이던 문제입니다.
스레드 멘션을 볼 때 앱이 충돌하던 문제입니다.
기기를 웹캠으로 사용할 때 화질이 저하되던 문제입니다.
화면이 무작위로 꺼졌다 켜지던 문제와 WPA-Enterprise PEAP 방식 Wi-Fi 로그인 실패 문제도 포함됩니다.

테스트 방법​

베타 빌드는 Android Beta Program에 가입하면 OTA로 받을 수 있습니다.
직접 이미지를 설치하는 경우에는 OTA 이미지를 사이드로드하는 방식을 사용합니다.

adb sideload ota.zip

에뮬레이터에서는 x86 64비트와 ARM v8-A 이미지가 지원됩니다.
베타 빌드에서는 보안 패치 수준을 코드로 확인할 수도 있습니다.

val patch = Build.VERSION.SECURITY_PATCH
Log.d("DeviceInfo", "Security patch: $patch")

실무 관점​

MTS와 같은 금융 앱에서는 베타 빌드 테스트의 목적을 분명히 정하는 것이 좋습니다.
API 변경이 없는 업데이트에서는 신규 API 대응보다 회귀 테스트가 우선입니다.
렌더링과 화면 전환, 카메라와 Wi-Fi 관련 수정이 포함된 만큼 해당 경로의 스모크 테스트를 먼저 수행합니다.
베타 빌드는 업무용 주력 기기가 아니라 테스트 전용 기기나 에뮬레이터에서 검증하는 것이 안전합니다.
베타에서 발견한 문제는 Beta Feedback 앱이나 이슈 트래커로 보고하는 흐름을 팀 안에 정해두면 좋습니다.

마치며​

QPR3 Beta 3는 API 변경 없이 26건의 문제를 다듬은 베타 빌드입니다.
정식 출시 전에 테스트 기기에서 회귀 테스트를 한 번 돌려보는 것이 이번 업데이트의 실용적인 대응입니다.

Android 17 QPR3 Beta 2 살펴보기

2026년 10월 26일 · 약 4분
Way
Android Developer

안녕하세요, 한국투자증권에서 한투-한국투자증권 개발을 담당하고 있는 way입니다.
2026년 10월 20일에 공개된 Android 17 QPR3 Beta 2에 대해 설명해드리겠습니다.

배경​

QPR은 Quarterly Platform Release의 약자입니다.
Android 17의 초기 릴리스 이후 분기 단위로 수정 사항과 개선 사항을 제공하는 업데이트 방식입니다.
QPR은 AOSP와 Pixel 기기의 Feature Drop으로 함께 제공됩니다.
앱에 영향을 주는 API 변경은 포함하지 않는 것이 특징입니다.
그럼에도 Google은 최신 QPR 베타 빌드의 이미지를 제공합니다.
앱에 영향을 줄 수 있는 변화가 있는지 미리 테스트해 볼 수 있도록 하기 위함입니다.
공식 Android 17 QPR3 릴리스 노트를 기준으로 정리합니다.

Beta 2 살펴보기​

빌드 정보​

Beta 2의 릴리스 날짜는 2026년 10월 20일입니다.
빌드는 DP11.261002.005이며, 보안 패치 수준은 2026-10-05입니다.
Google Play 서비스 버전은 26.36.33입니다.
에뮬레이터는 x86 64비트와 ARM v8-A를 지원합니다.
테스트 기기나 에뮬레이터에서 빌드를 확인하는 방법은 다음과 같습니다.

adb shell getprop ro.build.display.id

Beta 2에서 수정된 주요 이슈​

Beta 2의 수정 목록은 대부분 기기 동작과 시스템 UI에 집중되어 있습니다.
앱 개발 관점에서 눈여겨볼 만한 항목은 다음과 같습니다.

  • 기기가 간헐적으로 충돌하고 재부팅되는 문제
  • 모바일 데이터 사용 중 인터넷 퀵 세팅 타일에 텍스트가 계속 표시되는 문제
  • 외부 오디오 기기 연결 시 미디어 출력 대화상자가 모노크롬 시스템 테마를 무시하는 문제
  • 공유 시트에서 고정된 앱 옆 핀 아이콘 위치가 어긋나는 문제
  • 내부 PublishedApi 선언이 API lint와 소스 호환성 검사 오류를 유발하는 문제
  • WhatsApp 영상 통화 중 기기가 예기치 않게 종료되는 문제
  • 잠금 화면 진행 중 알림이 다른 UI 요소와 겹치고 패널 애니메이션이 끊기는 문제
  • 화면 회전 후 화면 녹화가 멈추고 프레임 캡처가 중단되는 문제
  • 표시 크기와 무관하게 시스템 UI, 글꼴, 앱이 비정상적으로 작게 렌더링되는 문제
  • 통화 종료 후 화면이 검게 변하고 응답하지 않는 문제
  • Face Unlock이나 카메라 사용 후 모션 센서가 계속 활성 상태로 남아 배터리가 소모되는 문제
  • Bluetooth 페어링 시간 초과로 페어링이 실패하는 문제
  • 앱 서랍에서 키보드 언어 전환 시 앱 서랍이 예기치 않게 닫히는 문제

Beta 1에서 이미 수정된 내용​

Beta 1은 2026년 10월 2일에 공개되었습니다.
빌드는 DP11.260918.005와 DP11.260918.006입니다.
앱 동작과 직접 연결되는 수정 사항도 포함되어 있습니다.

  • 미디어 컨트롤이 없는 앱에서 오디오 재생 중 출력 기기를 전환할 수 없던 문제
  • 퀵 세팅 타일에서 포그라운드 서비스를 시작할 때 앱이 충돌하던 문제
  • NFC 서비스가 첫 태그 스캔 후 DeadObjectException으로 충돌하고 태그 감지를 중단하던 문제
  • 지문 센서 잠금 해제 시 기기가 멈추고 응답하지 않던 문제
  • 눈을 뜬 상태 요구 옵션 선택 시 기기가 충돌하던 문제
  • ASCII가 아닌 오디오 속성 태그 처리 시 MediaPlayer가 충돌하던 문제
  • 앱 실행 시 멈추고 ANR이 발생하던 문제
  • 데스크톱 모드에서 외부 디스플레이를 사용하는 영상 통화 앱의 카메라 피드가 90도 회전하던 문제

실무 관점​

QPR 베타는 API 변경이 없는 업데이트입니다.
그래서 신규 API 대응보다는 기존 기능의 회귀 테스트가 중심이 됩니다.
베타 빌드는 실사용 기기가 아니라 별도 테스트 기기나 에뮬레이터에서 확인하는 것이 안전합니다.
이번 수정 목록에는 통화, 생체 인증, 화면 녹화와 관련된 항목이 포함되어 있습니다.
MTS 앱에서도 고객 문의로 들어올 수 있는 증상과 겹치는지 한 번 점검해 볼 만합니다.
빌드 번호와 보안 패치 수준을 기록해 두면, 이후 정식 릴리스와 비교할 때 기준점이 됩니다.

마치며​

Android 17 QPR3 Beta 2는 API 변경 없이 기기 안정성과 시스템 UI를 다듬는 업데이트입니다.
정식 릴리스 전에 테스트 기기에서 한 번 돌려보고, 회귀가 없는지 확인해 두는 것이 좋습니다.
