Java와 Kotlin by IntelliJ IDEA 1.0, VS Code와 Cursor에서 쓰는 IntelliJ의 언어 지능

2026년 10월 31일 · 약 4분
Way
Android Developer

안녕하세요, 한국투자증권에서 한투-한국투자증권 개발을 담당하고 있는 way입니다.
2026년 10월에 정식 1.0으로 공개된 Java and Kotlin by IntelliJ IDEA에 대해 설명해드리겠습니다.

배경​

에이전트가 구현을 맡는 비중이 커지면서 개발자의 편집 방식도 바뀌고 있습니다.
직접 코드를 길게 쓰는 시간보다 선언으로 이동하고 참조를 찾고 이름을 바꾸는 시간이 늘었습니다.
이런 기능은 Language Server Protocol이 태어난 이유와 정확히 맞닿아 있습니다.
언어 지원을 한 번 구현하면 LSP를 지원하는 어떤 에디터에서도 재사용할 수 있습니다.
JetBrains은 이런 흐름에 맞춰 IntelliJ IDEA의 JVM 언어 지능을 IDE 밖으로 꺼냈습니다.
프리뷰 공개 약 10주 뒤, VS Code와 Cursor용 확장 기능이 1.0에 도달했습니다.

Java and Kotlin by IntelliJ IDEA 1.0 살펴보기​

1.0에 담긴 기능​

1.0은 IntelliJ IDEA 데스크톱 IDE와 같은 Java와 Kotlin 언어 기술을 사용합니다.
Java와 Kotlin, 혼합 언어 프로젝트를 지원합니다.
스마트 코드 완성과 탐색, 코드 분석을 제공합니다.
리팩터링과 에디터 보조 기능도 포함되어 있습니다.
Maven과 Gradle, Bazel 빌드 도구를 지원합니다.
대규모 프로젝트와 모노레포에서도 빠른 성능을 목표로 합니다.
테스트 러너는 현재 JUnit을 지원합니다.
디버깅은 에뮬레이션된 중단점과 비동기 스택 트레이스를 포함합니다.

설치 방법​

확장 기능은 Visual Studio Marketplace나 Open VSX Registry에서 받을 수 있습니다.
에디터 안에서는 명령 팔레트에 아래 명령을 붙여넣는 방식으로 설치합니다.
Cursor에서는 IDE 모드로 전환한 뒤 같은 명령을 사용합니다.

.ext install JetBrains.intellij-server

설치가 끝나면 프로젝트를 열 때 빌드 파일을 기준으로 가져오기가 진행됩니다.
Maven과 Gradle, Bazel 중 프로젝트에 맞는 빌드 파일을 자동으로 인식합니다.
가져오기가 끝나면 Java와 Kotlin 언어 기능이 에디터에서 활성화됩니다.

Cursor 전용 지원​

Cursor에서는 Agents Window 전용 지원이 따로 마련되어 있습니다.
Agents Window는 자체 언어 서버 인스턴스를 이용해 분석 기능을 제공할 수 있습니다.
JSpecify 기반 널 가능성 지원과 Spring Framework 특화 분석이 포함됩니다.
이 출시는 Cursor 팀과의 긴밀한 협업으로 만들어졌다고 JetBrains은 설명합니다.

팀에서 함께 쓰기 위한 설정​

팀원 모두가 같은 확장을 쓰도록 권장 목록 파일로 공유할 수 있습니다.
프로젝트 루트에 아래 파일을 두면 VS Code가 확장 설치를 권합니다.

{
  "recommendations": [
    "JetBrains.intellij-server"
  ]
}

충돌 주의 사항​

Red Hat이나 Oracle의 Java 확장과는 코드 분석과 빠른 수정 기능이 겹칩니다.
동작이 중복되거나 충돌할 수 있으므로 함께 쓸 때는 해당 확장을 비활성화하는 것이 권장됩니다.
Spring 팀의 Spring Tools와는 함께 잘 동작하도록 맞춰져 있습니다.

라이선스 변경 사항​

1.0부터는 프리뷰 단계의 무료 제공이 끝났습니다.
30일 평가판 이후에는 IntelliJ IDEA Ultimate 구독이 필요합니다.
하나의 라이선스로 데스크톱 IDE와 VS Code 계열 에디터를 함께 쓸 수 있습니다.
라이선스는 인간 사용을 기준으로 설계되었습니다.
순수 에이전트 사용을 위한 라이선스 모델은 추후 안내될 예정입니다.

실무 관점​

Android Studio가 주 IDE인 팀이라면 이 확장이 주 IDE를 대체하지는 않습니다.
Cursor나 VS Code에서 코드 리뷰나 에이전트 작업을 할 때 IntelliJ 수준의 분석을 빌려오는 용도가 맞습니다.
Gradle 프로젝트는 빌드 파일 기준으로 가져오기가 진행되므로 모듈 구조가 복잡하면 초기 인덱싱 시간을 봐야 합니다.
팀 단위로 도입하기 전에는 Ultimate 구독 비용과 평가판 종료 시점을 먼저 확인하는 것이 좋습니다.
기존 Java 확장을 끄는 설정까지 권장 파일에 함께 정리해 두면 온보딩 마찰이 줄어듭습니다.

마치며​

Java와 Kotlin by IntelliJ IDEA 1.0은 IDE 밖에서도 IntelliJ의 언어 지능을 쓸 수 있게 한 릴리스입니다.
에이전트 시대의 편집 방식에 맞춰 탐색과 리팩터링 같은 핵심 기능에 집중한 구성이 돋보입니다.
