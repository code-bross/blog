안녕하세요, [한국투자증권](https://securities.koreainvestment.com/main/Main.jsp)에서 [한투-한국투자증권](https://play.google.com/store/apps/details?id=com.truefriend.neosmartarenewal&hl=ko) 개발을 담당하고 있는 way입니다.<br/>
2026년 11월에 Canary 채널로 공개된 [SDK Platform Tools](https://developer.android.com/tools/releases/platform-tools) 37.0.2에 대해 설명해드리겠습니다.<br/>
이번 릴리스는 adb의 USB 백엔드 교체와 설치 옵션 정리가 중심입니다.<br/>

### 배경

adb는 Android Studio가 함께 설치하는 복사본을 쓰는 경우가 많습니다.<br/>
그러나 명령줄에서 직접 쓰거나 CI 환경에서 쓸 때는 Platform Tools를 별도로 받습니다.<br/>
최근 릴리스는 adb의 내부 구조를 바꾸는 방향으로 이어지고 있습니다.<br/>
37.0.1(2026년 7월)에서는 Windows의 USB 백엔드가 libadbusb로 교체되었고, 37.0.0(2026년 2월)에서는 mDNS 백엔드가 libadbmdns로 바뀌었습니다.<br/>
37.0.2는 같은 흐름을 Linux와 macOS로 넓힙니다.<br/>
여기에 더해 설치 옵션 하나가 deprecated 되었고, 다음 릴리스에서 제거될 예정입니다.<br/>

### SDK Platform Tools 37.0.2 살펴보기

#### libadbusb로 USB 백엔드 교체하기

Linux와 macOS에서 레거시 USB 백엔드가 libadbusb로 교체됩니다.<br/>
Linux에서는 netlink 핫플러그 대신 1000ms 간격의 USB 버스 폴링을 사용합니다.<br/>
폴링 간격은 `ADB_USB_LINUX_POLL_INTERVAL_MS` 환경 변수로 바꿀 수 있습니다.<br/>
레거시 백엔드로 되돌리려면 `ADB_USB_LEGACY=1`을 설정합니다.<br/>
인플레이스 USB 리셋이나 동시 `start-server` 경합 뒤에 기기를 놓치던 문제를 줄이는 것이 목적입니다.<br/>
Linux 레거시 백엔드에는 netlink 이벤트를 놓쳤을 때 기기를 복구하는 재연결 재시도 루프도 추가되었습니다.<br/>

```bash
# libadbusb 폴링 간격 바꾸기
export ADB_USB_LINUX_POLL_INTERVAL_MS=500
adb kill-server
adb devices
```

#### adb install --fastdeploy 종료 예고하기

`adb install --fastdeploy` 옵션이 deprecated 되었습니다.<br/>
대신 `android install` 명령을 사용합니다.<br/>
당분간은 `--deprecated-fastdeploy` 플래그로 계속 쓸 수 있지만, 37.0.3에서 제거됩니다.<br/>
CI 스크립트나 배포 스크립트에 fastdeploy가 남아 있다면 미리 교체해야 합니다.<br/>

```bash
# 기존 방식은 37.0.3에서 제거됩니다
adb install --fastdeploy app-debug.apk

# 37.0.2부터는 android install 명령을 사용합니다
android install app-debug.apk
```

#### adb sync에 dlkm 파티션 추가하기

`adb sync` 명령이 `system_dlkm`과 `vendor_dlkm`, `odm_dlkm` 파티션을 지원합니다.<br/>
동적 커널 모듈이 들어 있는 파티션을 동기화할 때 사용합니다.<br/>
플랫폼 이미지를 다루는 작업에서 동기화 범위가 넓어졌습니다.<br/>

#### 로그 양 줄이기와 macOS 충돌 수정하기

고빈도 데이터 플레인 로그가 verbose 레벨로 내려갔습니다.<br/>
읽기와 쓰기 같은 로그는 `usb:v`와 `transport:v`처럼 지정해야 보입니다.<br/>
대용량 로그 파일이 생기던 문제를 줄이는 변경입니다.<br/>
macOS에서는 Apple Silicon M6(macOS 27)에서 무시된 mDNS 레코드의 백트레이스를 수집하다가 adb 서버가 충돌하던 문제를 수정했습니다.<br/>
AMFI가 꺼진 상태에서 USB 기기를 연결할 때 발생하던 Mach 포트 예외 충돌도 수정했습니다.<br/>

```bash
# 필요한 경우에만 상세 로그를 켭니다
ADB_TRACE=usb:v,transport:v adb devices
```

### 실무 관점

37.0.2는 Canary 단계라 정식 릴리스가 아닙니다.<br/>
실무 기기에 바로 적용하기보다 테스트 환경에서 먼저 확인하는 것이 좋습니다.<br/>
fastdeploy를 쓰는 스크립트가 있다면 37.0.3 전에 `android install`로 교체해야 합니다.<br/>
Linux에서 USB 연결이 불안정했던 환경이라면 libadbusb 전환 뒤에 기기 인식이 안정되는지 확인해 볼 만합니다.<br/>
로그 양이 줄었으니 장시간 adb 로그를 남기는 자동화에서는 파일 크기가 줄어드는 효과를 기대할 수 있습니다.<br/>

Canary에서 먼저 확인하고, 정식 릴리스에 맞춰 스크립트와 도구를 정리해 두는 것이 좋습니다.<br/>
