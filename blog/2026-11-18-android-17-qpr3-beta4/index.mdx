안녕하세요, [한국투자증권](https://securities.koreainvestment.com/main/Main.jsp)에서 [한투-한국투자증권](https://play.google.com/store/apps/details?id=com.truefriend.neosmartarenewal&hl=ko) 개발을 담당하고 있는 way입니다.<br/>
11월 12일에 공개된 [Android 17 QPR3 Beta 4](https://developer.android.com/about/versions/17/qpr3/release-notes?hl=en)에 대해 설명해드리겠습니다.<br/>

### 배경

QPR은 분기마다 배포되는 플랫폼 릴리스입니다.<br/>
메이저 버전 사이의 공백을 메우며 기능 개선과 보안 패치를 함께 전달합니다.<br/>
QPR3 Beta 4는 10월 2일에 시작된 QPR3 베타 사이클의 네 번째 빌드입니다.<br/>
Beta 3은 10월 29일에, Beta 2는 10월 20일에 배포되었습니다.<br/>
이번 베타는 앱에 영향을 주는 API 변경을 포함하지 않습니다.<br/>
대신 시스템 안정성과 수정 사항 검증이 중심이며, 개발자는 베타 이미지로 앱을 미리 테스트할 수 있습니다.<br/>

### Android 17 QPR3 Beta 4 살펴보기

#### 릴리스 정보

빌드 번호는 `DP11.261030.003`입니다.<br/>
보안 패치 수준은 2026-10-05이며, Google Play services는 26.41.31이 포함됩니다.<br/>
에뮬레이터는 x86 64비트와 ARM v8-A를 지원합니다.<br/>
대상 기기는 Pixel 6a부터 Pixel 11 시리즈와 Pixel Fold, Pixel Tablet까지입니다.<br/>
Pixel 6과 Pixel 6 Pro는 QPR1 베타 사이클 이후 지원이 종료되어 이번 베타 대상에서 제외됩니다.<br/>

#### Beta 4에서 수정된 주요 이슈

공식 [릴리스 노트](https://developer.android.com/about/versions/17/qpr3/release-notes?hl=en)에 따르면 Beta 4에서 수정된 주요 이슈는 다음과 같습니다.<br/>
`system_server` 메모리 누수로 인한 심각한 UI 지연, Pixel Launcher 충돌, 예기치 않은 기기 재시작이 수정되었습니다.<br/>
API 레벨 36을 대상으로 하는 앱에서 TLSv1 또는 TLSv1.1 연결이 거부될 때 Conscrypt가 불명확한 `IllegalArgumentException` 메시지를 던지던 문제가 수정되었습니다.<br/>
텍스트 입력 중 화면 키보드가 잘려 보이던 문제가 수정되었습니다.<br/>
과도한 블루투스 백그라운드 활동으로 배터리가 빠르게 소진되던 문제가 수정되었습니다.<br/>

#### TLS 1.0과 1.1 거부에 대비하기

API 레벨 36을 대상으로 하는 앱은 TLSv1과 TLSv1.1을 사용할 수 없습니다.<br/>
연결 시도가 거부되면 예외가 발생하므로, 오래된 TLS 버전에 의존하는 네트워크 코드는 점검이 필요합니다.<br/>
서버가 TLS 1.2 이상을 지원하는지 먼저 확인해야 합니다.<br/>
네트워크 보안 설정은 다음과 같이 작성할 수 있습니다.<br/>

```xml
<network-security-config>
    <base-config cleartextTrafficPermitted="false">
        <trust-anchors>
            <certificates src="system" />
        </trust-anchors>
    </base-config>
</network-security-config>
```

`cleartextTrafficPermitted`를 `false`로 두면 평문 통신이 차단됩니다.<br/>
신뢰하는 인증서는 시스템 저장소로 제한됩니다.<br/>

#### 베타 빌드 설치하고 확인하기

베타에 등록된 기기에는 OTA 업데이트가 제공됩니다.<br/>
팩토리 이미지는 [Android Flash Tool](https://flash.android.com/)로 직접 설치할 수도 있습니다.<br/>
개발자용 GSI 바이너리도 같은 빌드로 제공됩니다.<br/>
설치 후에는 다음 명령으로 빌드 번호와 보안 패치 수준을 확인할 수 있습니다.<br/>

```bash
adb shell getprop ro.build.version.incremental
adb shell getprop ro.build.version.security_patch
```

`ro.build.version.incremental`이 `DP11.261030.003`이면 Beta 4가 설치된 상태입니다.<br/>

### 실무 관점

MTS처럼 실시간 통신이 중요한 앱에서는 `system_server` 메모리 누수 수정이 체감 성능에 직접 영향을 줍니다.<br/>
API 레벨 36을 대상으로 한다면 TLS 버전 정책을 빌드 전에 확인해야 합니다.<br/>
베타 기기는 테스트 전용으로 유지하고, 실사용 기기에 베타를 설치하지 않는 것이 안전합니다.<br/>
정식 릴리스 일정은 아직 공개되지 않았으므로, 베타 결과를 기록해 두었다가 정식 릴리스 때 다시 확인하는 것이 좋습니다.<br/>

### 마치며

Beta 4는 UI 지연과 재시작, TLS 오류 메시지 같은 실사용 문제를 다듬는 업데이트입니다.<br/>
대상 API 36 앱이라면 TLS 설정을 이번 기회에 점검하는 것이 좋습니다.<br/>
