안녕하세요, [한국투자증권](https://securities.koreainvestment.com/main/Main.jsp)에서 [한투-한국투자증권](https://play.google.com/store/apps/details?id=com.truefriend.neosmartarenewal&hl=ko) 개발을 담당하고 있는 way입니다.<br/>
2026년 10월 7일, Compose 1.13.0-beta01이 릴리스됐습니다. stable 채널의 최신은 1.12.1입니다.<br/>
runtime 기준으로 실무에 닿는 변경만 추려서 정리합니다.

### Kotlin 2.2 타깃으로 상향

1.13부터 Compose 라이브러리는 Kotlin 2.2를 타깃으로 빌드되고, kotlinc 2.2가 필요합니다.<br/>
버전 카탈로그에서 Compose BOM만 올리는 습관이 있다면, Kotlin 플러그인 버전이 뒤처진 모듈에서 먼저 걸릴 수 있으니 함께 확인하는 게 좋습니다.

### Dp.Unspecified를 받는 컴포저블이 스킵되지 않던 버그

개인적으로 이번 베타에서 가장 반가운 수정입니다.<br/>
`Float.NaN`이나 `Double.NaN`을 인자로 받는 `@Composable`은 인자가 그대로여도 스킵되지 않고 매번 리컴포지션되는 버그가 있었습니다. `Dp.Unspecified`가 내부적으로 `Float.NaN` 기반이라, 선택적 간격이나 크기를 `Dp.Unspecified` 기본값으로 받는 공용 컴포넌트가 조용히 리컴포지션 비용을 치르고 있었던 셈입니다.

```kotlin
// 이런 공용 컴포넌트가 인자 변화가 없어도 스킵되지 않을 수 있었다
@Composable
fun PriceRow(
    label: String,
    topPadding: Dp = Dp.Unspecified
) { /* ... */ }
```

사내 디자인 시스템처럼 공용 컴포넌트에 `Dp.Unspecified` 기본값이 흔한 코드베이스라면, 1.13 stable이 나올 때 체감 성능이 좋아질 수 있습니다.

### computedStateOf 계산 블록은 읽기 전용으로 강제

`computedStateOf`의 계산 블록 안에서 상태에 쓰면 이제 `IllegalStateException`이 발생합니다.<br/>
기존에 계산 블록 안에서 쓰기까지 하던 코드가 있었다면 런타임에서 바로 드러나니, 베타를 올리는 모듈부터 확인이 필요합니다.

### 그 외 버그 픽스

- `CompositionObserver`가 컴포지션 패스마다 한 번만 해석되고, 교체는 다음 패스부터 적용됩니다. movable content 삽입 시에도 begin/end 콜백이 보고됩니다.
- `movableContent` 이동 시 래퍼 그룹 슬롯이 남아 있던 LinkComposer 메모리 누수를 고쳤습니다.
- `lifecycle-runtime` 의존성이 2.10.0으로 올라갔습니다. 번들된 lifecycle lint 검사는 AGP 9.5.0-alpha04 이상과 맞물려 있으니, AGP 베타 채널을 쓰는 프로젝트는 같이 보는 게 좋습니다.
- `ComposeTracer`를 메인 스레드 밖에서도 쓸 수 있게 됐습니다.

### 올릴까 말까

1.12.1 stable은 1.12.0에서 변경이 없는 버전이라, 운영 앱은 stable 유지가 무난합니다.<br/>
베타는 성능 검증이 필요한 화면(공용 컴포넌트를 많이 쓰는 MTS 특성상 리컴포지션 이슈가 체감되는 곳) 위주로 먼저 올려 보고, 앱 전체 확대는 stable 이후가 안전해 보입니다.
