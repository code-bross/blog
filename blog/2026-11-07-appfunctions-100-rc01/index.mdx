### 배경

AppFunctions는 앱의 기능을 AI 에이전트가 호출할 수 있게 노출하는 Jetpack 라이브러리입니다.<br/>

RC는 API 표면이 확정된 예비 stable 릴리스입니다.<br/>
에이전트는 기능을 직접 실행하는 대신, 앱이 선언한 설명을 보고 호출합니다.<br/>

### AppFunctions 1.0.0-rc01 살펴보기

#### 의존성을 추가합니다

```kotlin
dependencies {
    implementation("androidx.appfunctions:appfunctions:1.0.0-rc01")
    ksp("androidx.appfunctions:appfunctions-compiler:1.0.0-rc01")
}
```

테스트용 아티팩트도 같은 버전으로 제공됩니다.<br/>
Android 16(API 36) 이상에서 동작하며, `compileSdk` 36이 필요합니다.<br/>

#### 기능을 선언합니다

```kotlin
@AppFunctionServiceEntryPoint
class MarketFunctions {

    /**
     * 보유 종목의 현재가를 조회합니다.
     *
     * @param symbol 종목 코드입니다.
     * @return 현재가 정보입니다.
     */
    @AppFunctionDeclaration(isDescribedByKDoc = true)
    suspend fun getStockPrice(symbol: String): StockPrice {
        return withContext(Dispatchers.IO) {
            stockRepository.getPrice(symbol)
        }
    }
}
```

선언은 `@AppFunctionServiceEntryPoint`가 붙은 서비스 클래스 안에 둡니다.<br/>
`@AppFunctionDeclaration`이 붙은 함수는 외부 앱이 호출할 수 있습니다.<br/>
KSP 컴파일러가 함수 설명을 XML로 만들어 `assets`에 넣고, 시스템이 이를 색인합니다.<br/>
`isDescribedByKDoc`은 KDoc을 에이전트용 설명으로 쓸지 정합니다.<br/>
beta01부터 기본값이 없어 반드시 지정해야 합니다.<br/>

#### 기본적으로 메인 스레드에서 실행됩니다

선언한 함수는 기본적으로 메인 스레드에서 실행됩니다.<br/>
네트워크나 파일 작업이 있으면 `suspend` 함수로 만들고 디스패처를 바꿉니다.<br/>
호출자는 `EXECUTE_APP_FUNCTIONS` 권한이 필요합니다.<br/>
사용자 정의 타입을 주고받을 때는 직렬화 규칙을 따라야 합니다.<br/>

#### RC01 변경점

버전이 RC로 올라갔고, 기존 집계 컴파일러 옵션이 제거됐습니다.<br/>
Java 라이브러리 desugaring을 켠 앱에서 `java.time` 파라미터 역직렬화가 실패하던 문제가 수정됐습니다.<br/>
테스트는 Android 17 기기나 에뮬레이터에서 `adb shell cmd app_function` 명령으로 할 수 있습니다.<br/>

### 실무 관점

노출하는 기능은 읽기 전용 조회부터 시작하는 것이 안전합니다.<br/>
주문처럼 돈이 움직이는 기능은 에이전트에 노출하지 않습니다.<br/>
프로덕션 배포는 Connected Apps Platform 프리뷰 등록이 별도로 필요합니다.<br/>
설명 문구는 에이전트가 기능을 선택하는 기준이 되므로, KDoc을 정확히 씁니다.<br/>

### 마치며

AppFunctions가 RC에 들어서면서 에이전트 연동 준비가 한결 가까워졌습니다.<br/>
조회 기능부터 작은 범위로 적용해보고, 안정 버전에서 범위를 넓히겠습니다.<br/>
