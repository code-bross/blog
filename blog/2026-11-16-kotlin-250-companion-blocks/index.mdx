11월 11일에 공개된 [Kotlin 2.5.0-RC](https://github.com/JetBrains/kotlin/releases/tag/v2.5.0-RC)의 동반자 블록과 동반자 확장에 대해 설명해드리겠습니다.<br/>
동반자 블록과 동반자 확장은 [Kotlin 2.5.0-RC의 새로운 기능](https://kotlinlang.org/docs/whatsnew-eap.html)에 포함된 실험적 기능입니다.<br/>

### 배경

타입 이름으로 접근하는 멤버를 선언하려면 동반자 객체가 필요했습니다.<br/>
동반자 객체가 없는 타입에는 이런 멤버를 확장으로 추가할 방법이 없었습니다.<br/>
팩토리 함수나 상수를 타입 이름 아래에 두고 싶어도 동반자 객체를 먼저 만들어야 했습니다.<br/>
동반자 블록과 동반자 확장은 이 제약을 없애는 기능입니다.<br/>

### 동반자 블록과 확장 살펴보기

#### 동반자 블록

동반자 블록은 클래스나 인터페이스 안에 `companion` 블록을 직접 작성하는 방식입니다.<br/>
별도의 객체 인스턴스를 만들지 않고 멤버를 선언할 수 있습니다.<br/>
JVM에서는 정적 멤버로 생성되므로 `JvmStatic` 애너테이션이 필요 없습니다.<br/>

```kotlin
data class Vector(val x: Double, val y: Double) {
    companion {
        val Zero: Vector get() = Vector(0.0, 0.0)
    }
}

fun main() {
    println(Vector.Zero) // Vector(x=0.0, y=0.0)
}
```

#### 동반자 확장

동반자 확장은 최상위 확장에 `companion` 변경자를 붙이는 방식입니다.<br/>
확장 대상 타입에 동반자 객체가 없어도 타입 이름으로 접근하는 멤버를 선언할 수 있습니다.<br/>
타입을 직접 제어하지 않는 경우에도 멤버를 추가할 수 있습니다.<br/>

```kotlin
import kotlin.math.cos
import kotlin.math.sin

companion val Vector.UnitX get() = Vector(1.0, 0.0)

companion fun Vector.unit(angle: Double) = Vector(cos(angle), sin(angle))

fun main() {
    println(Vector.UnitX) // Vector(x=1.0, y=0.0)
}
```

#### 사용 설정

실험적 기능이므로 컴파일러 옵션을 추가해야 합니다.<br/>
동반자 블록만 쓰려면 다음 옵션을 사용합니다.<br/>

```kotlin
kotlin {
    compilerOptions {
        freeCompilerArgs.add("-Xcompanion-blocks")
    }
}
```

동반자 확장까지 쓰려면 다음 옵션을 사용합니다.<br/>

```kotlin
kotlin {
    compilerOptions {
        freeCompilerArgs.add("-Xcompanion-blocks-and-extensions")
    }
}
```

동반자 확장을 사용하면 컴파일러가 정식 출시 전 바이너리를 생성합니다.<br/>
그래서 동반자 확장을 쓰는 라이브러리는 기능이 정식화되기 전까지 의존성으로 소비할 수 없습니다.<br/>
설계 배경은 [동반자 블록과 확장 소개 글](https://blog.jetbrains.com/kotlin/2026/09/the-companions-to-come/)에서 확인할 수 있습니다.<br/>

### 실무 관점

MTS에서는 화면 상태나 요청 파라미터를 타입 이름 아래의 팩토리 함수로 만드는 경우가 많습니다.<br/>
동반자 블록을 쓰면 동반자 객체 선언 없이 이런 팩토리를 정리할 수 있습니다.<br/>
다만 실험적 기능이므로 앱 모듈에서 먼저 검증하고, 라이브러리 모듈에는 적용하지 않는 것이 좋습니다.<br/>
특히 동반자 확장은 바이너리 호환성에 영향을 주므로 공유 모듈에서는 피해야 합니다.<br/>

### 마치며

동반자 블록과 동반자 확장은 동반자 객체 없이 타입 이름으로 접근하는 멤버를 선언하는 방식을 제공합니다.<br/>
팩토리 함수와 상수 정리가 간결해집니다.<br/>
