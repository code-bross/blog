2026년 10월 28일에 열린 Android Dev Summit 2026에서 공개된 [AppFunctions](https://developer.android.com/ai/appfunctions)의 베타와 A2UI, ML Kit Agentic API에 대해 설명해드리겠습니다.<br/>

### 배경
사용자는 앱의 화면을 하나씩 눌러 가며 작업을 마치는 대신, 말로 요청하고 결과를 받는 방식에 익숙해지고 있습니다.<br/>
기존 앱은 화면 중심이라, 에이전트가 앱의 기능을 호출할 공식 경로가 없었습니다.<br/>
화면 자동화 방식은 깨지기 쉽고, 앱이 의도하지 않은 동작까지 허용할 위험이 있습니다.<br/>
AppFunctions는 앱이 스스로 공개한 기능만을 에이전트가 호출하게 만드는 구조입니다.<br/>

### AppFunctions와 에이전트 API 살펴보기

#### AppFunctions 베타
AppFunctions는 앱의 기능을 온디바이스 또는 시스템 에이전트에 노출하는 통합 도구 호출 계층입니다.<br/>
연결 방식은 Model Context Protocol 기반의 Android MCP이며, Android 16 이상 기기에서 동작합니다.<br/>
Jetpack 라이브러리는 2026년 10월 21일 기준 `1.0.0-beta01`이 공개되어 있습니다.<br/>
함수는 `AppFunction` 어노테이션으로 선언하고, KDoc 설명이 도구의 스키마로 함께 전달됩니다.<br/>
에이전트는 앱이 공개한 함수만 발견하고 실행하므로, 노출 범위를 앱 개발자가 직접 정할 수 있습니다.<br/>

```kotlin
dependencies {
    implementation("androidx.appfunctions:appfunctions:1.0.0-beta01")
    ksp("androidx.appfunctions:appfunctions-compiler:1.0.0-beta01")
}
```

```kotlin
@AppFunction(isDescribedByKDoc = true)
suspend fun getFavoriteStockPrice(
    symbol: String
): StockPrice {
    // 관심 종목의 현재 시세를 조회하는 함수입니다.
    return repository.getPrice(symbol)
}
```

#### A2UI 알파
에이전트의 답변이 텍스트로만 나오면, 사용자는 다시 앱 화면으로 돌아가 확인해야 합니다.<br/>
A2UI는 에이전트가 앱 자체의 컴포넌트로 만든 인터랙티브 화면을 그대로 보여주는 방식입니다.<br/>
Jetpack Compose용 네이티브 렌더러가 포함되어 있어, 에이전트 응답이 앱의 UI로 자연스럽게 이어집니다.<br/>
현재 알파 단계이며, AppFunctions와 함께 앱의 에이전트 경험을 구성하는 한 축입니다.<br/>

#### ML Kit Agentic API 알파
온디바이스에서 동작하는 에이전트 기능은 ML Kit의 Agentic API가 담당합니다.<br/>
Gemini Nano 4를 기반으로 하며, 함수 실행과 대화 기록 저장, 오케스트레이션 루프 관리, 자동 가드레일을 함께 제공합니다.<br/>
앱 안에서 도구를 실행하는 에이전트를 만들 때, 호출과 기록과 안전장치를 직접 구현하지 않아도 됩니다.<br/>
AppFunctions로 공개된 기능도 이 API를 통해 발견하고 실행할 수 있습니다.<br/>

#### Connected Apps Platform 프리뷰
앱의 서비스를 Gemini와 검색까지 연결하는 통로는 Connected Apps Platform 프리뷰가 담당합니다.<br/>
Android MCP나 원격 MCP 서버로 연동하고, Google Connected Console에서 등록해 관리합니다.<br/>
Google은 Adobe와 Peloton, Experian 등 50개 이상의 파트너 연동이 이미 Gemini 앱에서 동작하고 있다고 밝혔습니다.<br/>

#### 실무 관점
MTS 앱에 적용한다면, 노출할 함수의 범위를 정하는 일이 구현보다 먼저입니다.<br/>
주문이나 이체 같은 자금 이동 기능은 에이전트 호출 경로에 두지 않는 것이 안전합니다.<br/>
시세 조회나 관심 종목 확인처럼 읽기 전용 기능부터 베타 단계에서 검증하는 순서가 적절합니다.<br/>
아직 베타와 알파 단계라 API가 바뀔 수 있으므로, 노출 함수는 별도 모듈로 분리해 교체 비용을 낮추는 것이 좋습니다.<br/>

### 마치며
AppFunctions는 앱을 화면의 집합이 아니라 에이전트가 호출할 수 있는 기능의 집합으로 바꾸는 시도입니다.<br/>
A2UI와 온디바이스 Agentic API가 함께 갖춰지면서, 앱 안에서의 에이전트 경험이 텍스트 응답을 넘어 실제 화면 동작으로 이어지게 되었습니다.<br/>
