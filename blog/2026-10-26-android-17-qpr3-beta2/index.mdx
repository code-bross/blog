안녕하세요, [한국투자증권](https://securities.koreainvestment.com/main/Main.jsp)에서 [한투-한국투자증권](https://play.google.com/store/apps/details?id=com.truefriend.neosmartarenewal&hl=ko) 개발을 담당하고 있는 way입니다.<br/>
2026년 10월 20일에 공개된 Android 17 QPR3 Beta 2에 대해 설명해드리겠습니다.<br/>

### 배경

QPR은 Quarterly Platform Release의 약자입니다.<br/>
Android 17의 초기 릴리스 이후 분기 단위로 수정 사항과 개선 사항을 제공하는 업데이트 방식입니다.<br/>
QPR은 AOSP와 Pixel 기기의 Feature Drop으로 함께 제공됩니다.<br/>
앱에 영향을 주는 API 변경은 포함하지 않는 것이 특징입니다.<br/>
그럼에도 Google은 최신 QPR 베타 빌드의 이미지를 제공합니다.<br/>
앱에 영향을 줄 수 있는 변화가 있는지 미리 테스트해 볼 수 있도록 하기 위함입니다.<br/>
공식 [Android 17 QPR3 릴리스 노트](https://developer.android.com/about/versions/17/qpr3/release-notes)를 기준으로 정리합니다.<br/>

### Beta 2 살펴보기

#### 빌드 정보

Beta 2의 릴리스 날짜는 2026년 10월 20일입니다.<br/>
빌드는 DP11.261002.005이며, 보안 패치 수준은 2026-10-05입니다.<br/>
Google Play 서비스 버전은 26.36.33입니다.<br/>
에뮬레이터는 x86 64비트와 ARM v8-A를 지원합니다.<br/>
테스트 기기나 에뮬레이터에서 빌드를 확인하는 방법은 다음과 같습니다.<br/>

```text
adb shell getprop ro.build.display.id
```

#### Beta 2에서 수정된 주요 이슈

Beta 2의 수정 목록은 대부분 기기 동작과 시스템 UI에 집중되어 있습니다.<br/>
앱 개발 관점에서 눈여겨볼 만한 항목은 다음과 같습니다.<br/>

- 기기가 간헐적으로 충돌하고 재부팅되는 문제
- 모바일 데이터 사용 중 인터넷 퀵 세팅 타일에 텍스트가 계속 표시되는 문제
- 외부 오디오 기기 연결 시 미디어 출력 대화상자가 모노크롬 시스템 테마를 무시하는 문제
- 공유 시트에서 고정된 앱 옆 핀 아이콘 위치가 어긋나는 문제
- 내부 PublishedApi 선언이 API lint와 소스 호환성 검사 오류를 유발하는 문제
- WhatsApp 영상 통화 중 기기가 예기치 않게 종료되는 문제
- 잠금 화면 진행 중 알림이 다른 UI 요소와 겹치고 패널 애니메이션이 끊기는 문제
- 화면 회전 후 화면 녹화가 멈추고 프레임 캡처가 중단되는 문제
- 표시 크기와 무관하게 시스템 UI, 글꼴, 앱이 비정상적으로 작게 렌더링되는 문제
- 통화 종료 후 화면이 검게 변하고 응답하지 않는 문제
- Face Unlock이나 카메라 사용 후 모션 센서가 계속 활성 상태로 남아 배터리가 소모되는 문제
- Bluetooth 페어링 시간 초과로 페어링이 실패하는 문제
- 앱 서랍에서 키보드 언어 전환 시 앱 서랍이 예기치 않게 닫히는 문제

#### Beta 1에서 이미 수정된 내용

Beta 1은 2026년 10월 2일에 공개되었습니다.<br/>
빌드는 DP11.260918.005와 DP11.260918.006입니다.<br/>
앱 동작과 직접 연결되는 수정 사항도 포함되어 있습니다.<br/>

- 미디어 컨트롤이 없는 앱에서 오디오 재생 중 출력 기기를 전환할 수 없던 문제
- 퀵 세팅 타일에서 포그라운드 서비스를 시작할 때 앱이 충돌하던 문제
- NFC 서비스가 첫 태그 스캔 후 DeadObjectException으로 충돌하고 태그 감지를 중단하던 문제
- 지문 센서 잠금 해제 시 기기가 멈추고 응답하지 않던 문제
- 눈을 뜬 상태 요구 옵션 선택 시 기기가 충돌하던 문제
- ASCII가 아닌 오디오 속성 태그 처리 시 MediaPlayer가 충돌하던 문제
- 앱 실행 시 멈추고 ANR이 발생하던 문제
- 데스크톱 모드에서 외부 디스플레이를 사용하는 영상 통화 앱의 카메라 피드가 90도 회전하던 문제

### 실무 관점

QPR 베타는 API 변경이 없는 업데이트입니다.<br/>
그래서 신규 API 대응보다는 기존 기능의 회귀 테스트가 중심이 됩니다.<br/>
베타 빌드는 실사용 기기가 아니라 별도 테스트 기기나 에뮬레이터에서 확인하는 것이 안전합니다.<br/>
이번 수정 목록에는 통화, 생체 인증, 화면 녹화와 관련된 항목이 포함되어 있습니다.<br/>
MTS 앱에서도 고객 문의로 들어올 수 있는 증상과 겹치는지 한 번 점검해 볼 만합니다.<br/>
빌드 번호와 보안 패치 수준을 기록해 두면, 이후 정식 릴리스와 비교할 때 기준점이 됩니다.<br/>

### 마치며

Android 17 QPR3 Beta 2는 API 변경 없이 기기 안정성과 시스템 UI를 다듬는 업데이트입니다.<br/>
정식 릴리스 전에 테스트 기기에서 한 번 돌려보고, 회귀가 없는지 확인해 두는 것이 좋습니다.<br/>
