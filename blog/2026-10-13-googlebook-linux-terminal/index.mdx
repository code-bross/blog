핵심은 AI 에이전트에게 `sudo`를 줘도 시스템이 망가지지 않는 구조입니다.<br/>
자세한 내용은 [Android Developers Blog 원문](https://android-developers.googleblog.com/2026/10/googlebook-linux-terminal-preview-vm.html)에서 확인할 수 있습니다.<br/>

### 구글북 리눅스 터미널 살펴보기

#### VM 기반 격리 구조
- 모든 터미널 명령은 격리된 Linux VM 안에서만 실행됩니다.
- Antigravity 같은 AI 에이전트에 `sudo` 권한을 줘도 호스트 OS나 개인 파일이 오염되지 않습니다.
- VM에 공개하는 디렉터리는 사용자가 명시적으로 허용한 것만 마운트됩니다.
- 구글북 OS는 defense-in-depth 원칙으로 설계되었고, VM 경계가 호스트 OS와 마운트되지 않은 파일을 보호합니다.

#### 파일 유지와 원클릭 리셋
- 원클릭 VM 리셋으로 실험 환경을 초기화할 수 있습니다.
- VM을 초기화해도 파일은 호스트 파일 시스템에 그대로 유지됩니다.
- 리눅스 파일은 구글북 파일 앱에서도 보입니다.
- 에이전트에게 과감하게 권한을 주고, 망가지면 리셋하면 되는 구조입니다.

#### 개발자에게 익숙한 Debian 환경
- apt, git, ssh, 컴파일러·런타임 같은 익숙한 워크플로우가 그대로 들어옵니다.
- Node.js, Python, Ruby, Go, Rust 같은 모던 런타임을 지원합니다.
- localhost 포트 자동 포워딩으로 호스트 브라우저에서 바로 확인할 수 있습니다.
- VM에 할당하는 메모리는 워크로드에 맞게 조절할 수 있습니다.
- 구글 엔지니어들도 구글북으로 리눅스 커널을 빌드하고 플랫폼 엔지니어링에 터미널을 사용하고 있다고 합니다.

#### 로드맵
- Linux GUI 앱 지원이 예정되어 있습니다. 터미널을 넘어 GUI 앱까지 품으면 Android Studio 같은 도구를 VM에 올리는 시나리오도 열립니다.
- USB 패스스루와 ADB over USB가 지원될 예정입니다. 현재는 네트워크 패스스루와 무선 ADB가 있고, USB 패스스루가 오면 Linux VM과 Antigravity에서 직접 로컬 기기 디버깅이 가능해집니다.
- GPU/NPU 하드웨어 가속이 예정되어 있습니다. 40 TOPS급 NPU를 단 구글북 스펙과 맞물리는 부분입니다.
- VM 메모리·스토리지 동적 스케일링과 VM 지속성, 터미널 창 분리가 포함되어 있습니다. 장시간 도는 에이전트 작업을 위한 전제 조건입니다.

### 실무에서 주의할 점

아직 프리뷰 단계이므로 당장 개발 머신으로 사용하기는 이릅니다.<br/>
GUI 앱 지원과 USB ADB는 로드맵에 있는 항목입니다.<br/>
다만 보안 모델은 주목할 만합니다.<br/>
sudo를 줘도 되는 VM 샌드박스와 디렉터리별 명시적 마운트 허가, 원클릭 리셋은 사내에서 AI 코딩 에이전트 도입을 검토할 때 레퍼런스 아키텍처로 쓸 수 있습니다.<br/>
Antigravity가 구글북용으로 따로 나온다는 점과 결합하면, 구글은 노트북을 에이전트와 함께 일하는 머신으로 그리고 있습니다.<br/>
10월 2일 공개된 [Device Streaming and Android skills](https://android-developers.googleblog.com/) 흐름과 같은 방향입니다.<br/>
또한 9월 22일에 올라온 "Land your apps on Googlebook with adaptive development" 글과 함께 보면, 구글북은 Android 앱의 새 타깃 폼팩터이기도 합니다.<br/>
아직 구글북 실물이 없어 코드 실험은 못 하지만, 지금 당장 할 수 있는 정리는 다음과 같습니다.<br/>

```bash
# 1) 프로젝트에 에이전트용 가이드가 있는지 점검 (Android CLI skills 흐름과 연결)
ls .agent/ AGENTS.md CLAUDE.md 2>/dev/null

# 2) 무선 ADB로 에이전트가 기기를 만질 수 있는지 확인
adb devices -l          # 기기가 보이는지
adb shell settings get global adb_wifi_enabled
```
