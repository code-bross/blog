### 배경

Palette는 이미지에서 대표 색상을 추출하는 Jetpack 라이브러리입니다.<br/>
배너 이미지나 종목 대표 이미지에서 배경색과 텍스트 색을 뽑아 화면 테마에 맞추는 용도로 사용됩니다.<br/>
1.0.0 이후 오랜만에 공개된 1.1.0은 기능 추가보다 정리 성격이 강합니다.<br/>

### Palette 살펴보기

#### 대표 색 추출 방식

Palette는 비트맵의 픽셀을 양자화해 색상 군집을 만든 뒤 대표 스와치를 계산합니다.<br/>
동기 생성은 메인 스레드를 막을 수 있으므로, 실무에서는 비동기 생성이나 백그라운드 스레드에서 실행하는 것이 안전합니다.<br/>
추출할 색상 개수는 빌더에서 조절할 수 있으며, 기본값은 16개입니다.<br/>

```kotlin
val palette = Palette.from(bitmap)
    .maximumColorCount(24)
    .generate()
```

#### 스와치 종류

추출 결과는 용도별로 나뉜 스와치로 제공됩니다.<br/>
`getVibrantSwatch`는 생동감 있는 대표 색, `getMutedSwatch`는 차분한 대표 색을 돌려줍니다.<br/>
각각 밝은 버전과 어두운 버전이 있으며, `getDominantSwatch`는 이미지에서 가장 큰 비중을 차지하는 색을 돌려줍니다.<br/>
스와치는 null을 돌려줄 수 있으므로, 사용할 때는 반드시 대체 색을 함께 준비해야 합니다.<br/>

```kotlin
val vibrant = palette.getVibrantSwatch()
val muted = palette.getMutedSwatch()
val dominant = palette.getDominantSwatch()

val backgroundRgb = vibrant?.rgb ?: muted?.rgb ?: 0xFF1A1A1A.toInt()
val titleTextRgb = vibrant?.titleTextColor ?: 0xFFFFFFFF.toInt()
```

#### Compose에서 사용하기

Palette는 뷰 시스템 시절 라이브러리라 Compose 전용 API를 제공하지 않습니다.<br/>
비트맵을 받아 백그라운드에서 생성한 뒤, 결과 색을 Compose의 `Color`로 변환해 상태로 보관하는 방식이 일반적입니다.<br/>
이미지마다 한 번씩만 생성하고 결과를 캐시하면, 스크롤 화면에서도 반복 계산을 피할 수 있습니다.<br/>

```kotlin
@Composable
fun rememberPaletteColor(bitmap: Bitmap?): Color {
    var themeColor by remember { mutableStateOf(Color.Transparent) }
    LaunchedEffect(bitmap) {
        if (bitmap == null) return@LaunchedEffect
        val palette = withContext(Dispatchers.Default) {
            Palette.from(bitmap).generate()
        }
        val swatch = palette.getVibrantSwatch() ?: palette.getDominantSwatch()
        if (swatch != null) {
            themeColor = Color(swatch.rgb)
        }
    }
    return themeColor
}
```

#### 1.1.0에서 달라진 것

1.1.0의 가장 큰 변경은 JSpecify nullability 어노테이션 채택입니다.<br/>
Kotlin에서 엄격한 null 검사를 적용하려면 컴파일러 인자를 함께 설정해야 합니다.<br/>
또 하나의 변경은 `palette-ktx` 통합입니다.<br/>
Kotlin 확장 함수가 모두 메인 아티팩트로 들어갔고, `palette-ktx`는 호환 유지를 위한 빈 아티팩트로 남았습니다.<br/>
신규 프로젝트에서는 `palette`만 의존하면 되며, 기존 프로젝트에서는 `palette-ktx` 의존성을 정리할 수 있습니다.<br/>

```kotlin
dependencies {
    implementation("androidx.palette:palette:1.1.0")
}
```

```kotlin
kotlinOptions {
    freeCompilerArgs += listOf(
        "-Xjspecify-annotations=strict",
        "-Xtype-enhancement-improvements-strict-mode",
    )
}
```

### 실무 관점

이미지에서 뽑은 색을 그대로 텍스트 배경에 쓰면 가독성이 깨질 수 있습니다.<br/>
스와치가 제공하는 제목 텍스트 색과 본문 텍스트 색을 함께 사용해야 대비가 유지됩니다.<br/>
서버 이미지 색이 매번 달라지는 화면에서는, 색 추출 실패 시 기본 테마로 떨어지는 분기를 먼저 만들어 두는 것이 안전합니다.<br/>
MTS처럼 정보 밀도가 높은 화면에서는 전체 테마를 바꾸기보다, 배너 카드 내부 강조색 정도로 범위를 제한하는 편이 무난합니다.<br/>

### 마치며

Palette 1.1.0은 새 기능보다 nullability 정리와 아티팩트 통합에 초점이 맞춰져 있습니다.<br/>
기존 코드를 크게 바꾸지 않고 의존성만 정리할 수 있는 안정적인 업데이트입니다.<br/>
