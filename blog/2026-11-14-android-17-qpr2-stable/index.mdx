### 배경

QPR은 분기마다 배포되는 플랫폼 릴리스입니다.<br/>
메이저 버전 사이의 공백을 메우며 기능 개선과 보안 패치를 함께 전달합니다.<br/>

이번 QPR2는 일정보다 한 달 앞당겨 배포되었습니다.<br/>
작년 Android 16 QPR2가 12월에 배포된 것과 비교하면 이례적인 일정입니다.<br/>
11월 Pixel Drop과 2026년 11월 5일 보안 패치 수준이 함께 적용되었습니다.<br/>

대상 기기는 Pixel 6a부터 Pixel 11 시리즈까지 23종입니다.<br/>
Pixel Fold와 Pixel Tablet도 포함됩니다.<br/>
Pixel 6과 Pixel 6 Pro는 이번 릴리스 대상에서 제외되었습니다.<br/>
두 기기의 5년 업데이트 지원 기간이 2026년 10월에 종료되었기 때문입니다.<br/>

### Android 17 QPR2 살펴보기

#### 지원 기기와 빌드 번호

대부분의 기기에는 `CP4A.261105.040.A1` 빌드가 배포됩니다.<br/>
Pixel 11 시리즈는 지역에 따라 빌드 번호가 나뉩니다.<br/>
미국 모델은 `CP4A.261105.040.D1`, 캐나다 모델은 `CP4A.261105.040.B2`입니다.<br/>
배포는 단계적으로 진행되며 일주일 정도에 걸쳐 전 기기에 도달합니다.<br/>

단말에 적용된 보안 패치 수준은 코드에서도 확인할 수 있습니다.<br/>

```kotlin
val securityPatch = Build.VERSION.SECURITY_PATCH
// 기대값: 2026-11-05
```

또는 adb 명령으로 확인할 수 있습니다.<br/>

```shell
adb shell getprop ro.build.version.security_patch
```

#### 맞춤 설정과 블러 효과

시스템 색상을 직접 조절하는 슬라이더가 추가되었습니다.<br/>
강도는 Neutral, Soft, Bright, Bold 네 단계로 나뉩니다.<br/>
라이트 모드와 다크 모드에 각각 대응하는 적응형 배경화면도 지원됩니다.<br/>

개발자는 앱 안에서 새로운 블러 효과를 사용할 수 있습니다.<br/>
미디어 위에서 동작하는 오버레이에 적합한 형태로 개선되었습니다.<br/>
잠금 화면 위젯 편집 화면과 전원 메뉴의 블러 표현도 함께 다듬어졌습니다.<br/>

#### 상태 표시줄과 빠른 설정

상태 표시줄 옵션이 새로 추가되었습니다.<br/>
표시할 알림 종류와 시스템 모드 표시 여부를 선택할 수 있습니다.<br/>
빠른 설정에서는 앱이 실행 중일 때도 화면 밝기를 조절할 수 있습니다.<br/>
키보드 전환 버튼과 프린터 전송 시의 Live Updates 표시도 추가되었습니다.<br/>

#### 음성 브로드캐스트와 블루투스

Voice broadcast 기능이 추가되었습니다.<br/>
음성을 Auracast 수신 기기로 직접 스트리밍할 수 있습니다.<br/>
빠른 설정에 오디오 스트림 항목이 생겼고 Live Caption과 번역을 함께 사용할 수 있습니다.<br/>
블루투스 오디오에서 Gemini 음성과 미디어 음량 차이도 완화되었습니다.<br/>
암호화 DNS 서버 지원과 공유 시트 개선도 포함되었습니다.<br/>

#### 보안과 개인정보 보호

Private Compute Core logging 기능이 추가되었습니다.<br/>
AI 앱이 단말 데이터에 접근한 내역을 사용자가 직접 확인할 수 있습니다.<br/>
연락처 편집 권한 체계도 변경되었습니다.<br/>
기존처럼 권한만으로 연락처를 직접 수정하는 방식에서 벗어납니다.<br/>
통화 착신 전환을 이용한 사기 시도를 막는 보호 기능이 추가되었습니다.<br/>
멀티 SIM을 지원하는 SIM 보안 타임라인 뷰어도 제공됩니다.<br/>
사이드로딩 시 권한을 부여하는 절차도 간소화되었습니다.<br/>

#### 멀티태스킹과 접근성

폴더블 기기의 멀티태스킹이 개선되었습니다.<br/>
앱 핸들이 상단에 배치되고 분할 화면 전환이 부드러워졌습니다.<br/>
Bubbles의 위치 조정과 전체 화면 전환, 실행 동작도 개선되었습니다.<br/>
Linux Terminal에서는 실행 중인 리눅스 세션의 파일을 앱에서 탐색할 수 있습니다.<br/>
USB 웹캠으로 사용할 때의 화면과 화면 녹화 기본 동작도 변경되었습니다.<br/>
색상 인식 관련 조정과 블루투스 보청기 잠금 화면 제어 기능이 추가되었습니다.<br/>
선호하는 홈 시간대 설정과 키보드 진동 강도 조절 슬라이더도 제공됩니다.<br/>

### 실무 관점

QPR 릴리스는 OS 동작이 바뀌는 지점이라 실무 앱에 미치는 영향을 먼저 확인해야 합니다.<br/>
연락처 편집 권한 변경처럼 타깃 SDK와 무관하게 적용되는 변경이 포함될 수 있습니다.<br/>
Pixel 실기기가 있다면 보안 패치 수준부터 확인하고 주요 플로우를 회귀 테스트하는 것이 좋습니다.<br/>
베타 기간에 테스트했던 Quick Settings 레이아웃 편집 기능은 정식 릴리스에서 빠졌습니다.<br/>
베타에서 확인한 기능이 정식에 그대로 포함된다고 단정하지 않는 것이 좋습니다.<br/>
다음 분기 릴리스인 QPR3는 이미 베타가 진행 중이며 내년 봄 배포가 예상됩니다.<br/>

### 마치며

Android 17 QPR2는 맞춤 설정과 보안, 멀티태스킹을 함께 개선한 분기 릴리스입니다.<br/>
Pixel 6a 이후 기기를 사용 중이라면 단계적 배포 일정에 따라 순차적으로 받아볼 수 있습니다.<br/>
